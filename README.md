# FUTBOL-LE

Juego tipo Wordle para adivinar equipos de fútbol.

## Cómo jugar
- Adivina el equipo secreto del día en máximo 6 intentos
- Tras cada intento fallido se desbloquea una pista
- Pistas: País → Colores → Fundación → Ligas → Último título → Entrenador

## Tecnología
- React + Vite
- CSS puro
- Desplegado en Vercel

## Desarrollo local
```bash
npm install
npm run dev
```

## Despliegue
```bash
npm run build
# Subir carpeta 'dist' a Vercel
```
